# Tech Stack

## Front-end

| Technology | Purpose |
|---|---|
| React + TypeScript | UI framework with type safety |
| Tailwind CSS | Utility-first styling |
| React Router | Client-side routing |

## Back-end

| Technology | Purpose |
|---|---|
| Node.js + Express + TypeScript | HTTP server and API layer |
| Database sessions | Authentication (server-side session storage) |

## Database

| Technology | Purpose |
|---|---|
| PostgreSQL | Primary relational database |
| Prisma | ORM for schema management and queries |

## AI

| Technology | Purpose |
|---|---|
| Claude API (Anthropic) | Email classification, response generation, summaries, confidence scoring |

## Email

| Technology | Purpose |
|---|---|
| Gmail API (Google OAuth 2.0) | Read and send from the same inbox with Pub/Sub push notifications |
| SendGrid | Transactional email alternative |
| Mailgun | Transactional email alternative |

## Deployment

| Technology | Purpose |
|---|---|
| Docker | Containerization for consistent environments |
| AWS / Railway / Fly.io | Cloud hosting (to be decided) |
